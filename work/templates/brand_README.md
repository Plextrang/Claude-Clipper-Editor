# Real brand assets: use these, never draw stand-in logos or invented app icons

Generated by `python work/scripts/fetch_brand_assets.py` (list in `work/brand_assets.json`). Missing a brand? Fetch it, never
draw it: `--si <simple-icons slug>` (https://simpleicons.org), `--commons "<Wikimedia Commons file title>" <name>.svg` (official
full-colour logos; search https://commons.wikimedia.org), `--ui <material symbol name>` (https://fonts.google.com/icons).

## Use them (remotion/src/components/Brand.tsx)
```tsx
import {BrandLogo, Glyph} from '../components/Brand';
<BrandLogo name="premiere" width={120} />           // public/brand/premiere.svg, its own colours, never stretched
<Glyph name="thumb_up" size={40} color={C.ink} />    // UI glyph (Material Symbols Rounded), public/ui/thumb_up.svg
<Glyph name="thumb_up" fill size={40} color={C.ink} />  // filled variant
<Glyph brand="instagram" size={60} />               // simple-icons glyph in its brand colour (brand_colors.json)
```

## Rules
- A logo is shown as itself: own colours, own proportions, clear space around it, on a surface it reads on. Never recolour a
  logo to the palette, never put a complete app icon inside a second tile, never redraw one with text or shapes.
- The footage palette (theme tokens) colours everything AROUND the brand: backgrounds, cards, glows, captions, motion.
- Real UI = the real product's layout and glyphs (YouTube comment sheet, player and Studio; Instagram DMs and profile;
  Premiere Pro's dark panels and timeline; CapCut's mobile editor; TikTok's right-hand action rail; iOS notifications). Use
  the real glyphs from public/ui and the brand files here; text inside the UI is the video's words or neutral placeholders,
  never invented usernames, follower counts or quotes presented as real.

## Notes on specific files
| File | What it is |
|---|---|
| premiere.svg, after_effects.svg, photoshop.svg, illustrator.svg | Adobe app icons (dark rounded square + coloured letters). Adobe is NOT in simple-icons. |
| capcut_icon.svg | The COMPLETE CapCut app icon (its own white rounded tile, grey hairline, black glyph): show as-is, never box it. |
| capcut_logo.svg | CapCut glyph + wordmark. |
| youtube_icon.svg | YouTube play-button icon (red #FF0033 rounded rectangle, white triangle). |
| youtube_logo.svg | YouTube icon + "YouTube" wordmark, dark text: light backgrounds only. |
| instagram_icon.svg | Instagram app icon (gradient rounded square). instagram_glyph_gradient.svg: the camera glyph in the gradient. |
| tiktok_icon.svg, chatgpt.svg, davinci_resolve.svg | Official app logos. |
| si_<slug>.svg | Monochrome simple-icons glyphs (CC0): paint with `<Glyph brand=... />` (brand hex in brand_colors.json). |
| ../ui/<name>.svg, <name>-fill.svg | Material Symbols Rounded (Apache-2.0), the glyph family YouTube and Android use. |
