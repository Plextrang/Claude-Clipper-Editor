# Sound effect licences

Every file is either **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/), as stated on the official source page, or an original work made for this repo and dedicated to CC0.
Licences checked on 2026-10-28.

Processing (all files): converted to 48 kHz, 16-bit PCM WAV. Mono sources and dual-mono stereo became mono; true stereo stayed stereo.
Leading silence was trimmed (threshold -45 dB below peak, with 1 ms kept), as was trailing digital silence. Each file was peak-normalised to -3.0 dBFS.
Excerpts cut from a longer source got 10 ms fades. Processing was done with ffmpeg and numpy.
